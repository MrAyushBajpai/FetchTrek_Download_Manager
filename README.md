# FetchTrek Download Manager

A modular, high-performance desktop download acceleration manager and streaming/torrent client.

## Features
- Multi-connection segmented HTTP/HTTPS downloads with dynamic chunking.
- BitTorrent integration with DHT, PEX, and uTP support.
- Stream downloading (HLS/DASH media playlists) with lossless stream muxing.
- Out-of-process browser extension integration via Native Messaging Host.
- SQLite-backed state persistence with Write-Ahead Logging (WAL).
